# RunRate V1

**Tagline:** Freelancer Pricing & Runway Tool

## V1 Goal

Help a freelancer decide what to charge for a job by showing how different rates affect their financial runway.

## V1 Features

### 1. Account & Profile
- Sign up/create an account.
- Log in.
- Save freelancer profile.
- Save financial information so it is available when the freelancer returns.

### 2. Financial Setup
- Select freelancer category.
- Select NGN or USD.
- Enter monthly expenses.
- Enter current savings.
- Enter average income.
- Calculate current runway.

### 3. Job Pricing
- Enter/select work type.
- Enter estimated hours.
- Select experience level.
- Enter client budget.
- View a built-in estimated market-rate range.
- Use the built-in estimate or enter a personal market-rate range.

### 4. Financial Impact
- Choose whether normal average income continues as the baseline.
- Compare different possible job rates.
- See how each rate affects runway.

### 5. Pricing Decision
- Show the minimum rate.
- Show the suggested rate.
- Show the runway impact of different rates.

## V1 User Journey

Sign up → Save financial profile → Calculate runway → Enter job → Establish market rate → Choose income assumption → Compare rates → See minimum and suggested rate → Decide what to charge

## NOT NOW

- Additional currencies beyond NGN and USD.
- Automatic currency conversion.
- Bank/account connections.
- Invoicing.
- Payment collection.
- Advanced expense tracking.
- Client management.
- Job/project management.
- Advanced portfolio management.
- Automatic real-time market-rate data.
- Notifications and reminders.
- Teams or collaboration.
- Other features not required for the core pricing-and-runway journey.

## V1 Success Condition

A freelancer can create an account, save their financial information, return later, enter a potential job, compare rates, understand each rate's runway impact, see the minimum and suggested rates, and confidently decide what to charge.
